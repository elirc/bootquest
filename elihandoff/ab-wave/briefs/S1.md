## Build
1. `slateStructure(db, day)` reads, per track, the latest `slate_setting` row with `effective_day <= day`; no row →
   `track.slate_drills` + the default size. **Unconfigured default size = 1 drill per slate track** (4×1 + campaign
   step = 5 actions); `preset full` = today's 5 per track. No auto-ramp. Never UPDATE `track.slate_drills`.
2. Day-one defect to kill (C1): while a day is open `composeSlate` rebuilds the slate on each call
   (`streak.ts:296-306`). Prove with a test that the first verified drill pass does NOT change today's slate size.
3. `GET /settings/slate` (current + tomorrow's effective shape) and `PUT /settings/slate` (`{ preset }` or
   `{ tracks: [{ trackId, enabled, size? }] }`) → append rows with `effective_day` = tomorrow (local day). Validate
   track ids and sizes 1..10; refuse disabling every track.
4. Review slot: hidden (not shown as ticked) until a non-retest `review_item` existed before day start. Keep the
   slate derived; never store "done".
5. Phantom missed days (RULINGS R3.1): display-only. In `slateStatuses`, a `missed` day before the first learner
   action (earliest of attempt, review_log, xp_event) renders `none`. Do not touch `closeElapsedDays` or stored rows.
6. CLI: `bootquest slate` (show), `bootquest slate --tracks java,sysdesign --size 3`, `bootquest slate --preset
   full|default`; `bootquest today` exits non-zero on error instead of swallowing it (`cli/src/program.ts:226-231`).
7. Client: a "Choose your focus" card on the dashboard while no `slate_setting` row exists (tracks with checkboxes +
   size, Save = PUT, note "takes effect tomorrow"), plus a small settings link to change it later.
